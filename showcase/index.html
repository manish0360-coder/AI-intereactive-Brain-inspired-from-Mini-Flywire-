Brain-inspired agent, audited by its builder

I built an AI that looks like it thinks. Then I tested which parts really do.

MiniFlyWire is a 3D agent that moves through a small graph of concepts, choosing each next step from memory, reward, trust and curiosity.

Instead of claiming it was intelligent, I froze each experiment's design before seeing results and measured every mechanism. Most of the "cognitive" modules changed nothing. This page shows what survived.

In plain words

One agent, one question, one honest answer.

The agent

A browser app built with Three.js. A glowing dot walks a network of 20 ideas such as "recall", "predict" and "decide", trying to reach a goal while a live panel shows what it is "thinking".

The question

The app had modules named after brain functions: executive control, episodic memory, trust, look-ahead planning. Do they actually change the agent's behaviour, or do they only look good on screen?

The answer

My own audit found a scoring function over a fully visible map, not a mind. I repaired six real defects, then tested each mechanism under designs frozen before the outcome. Failures are published next to the wins.

How it works

How the agent makes one decision.

Every step runs the same loop. The agent stands on one node and must pick which connected node to visit next.

  1. Look around

    List the nodes connected to the current one. These are the only candidates.

  2. Score from experience

    60% of the score is a sum of about 36 learned terms: Q-values, distance to the goal, past rewards, habits, trust, a 3-step look-ahead and penalties for repeating itself.

  3. Let drives compete

    40% comes from arbitration: reward, meaning, confidence, curiosity, cost and schema signals compete for weight.

  4. Choose, with some chance

    epsilon-greedy over a softmax: usually the best option, and roughly 10 to 20% of the time a random one, to keep exploring.

  5. Move

    The agent travels the edge. In the test harness an edge can secretly fail, so the agent has to learn which paths are reliable.

  6. Learn

    Q-learning, reward memory and trust update from what happened, and the panel shows the new state.

FOUND IN AUDIT

The "executive controller" computes its weights on every step, but in a 3-seed, 3,000-step probe arbitration changed the top choice in 0 of 6,908 decisions. It is reported as open, not hidden.

Evidence board

What held, what failed, what was thrown out.

Each line is a study with a design frozen in git before its results existed. Numbers are mean paired differences with 95% intervals, copied from the results files in the repository.

The one result that replicated four times

A "goal-entry floor" (letting the goal-seeking score switch on before the agent has ever reached the goal) raises goal reaches without any stored memories. Extra goal reaches versus a cold start, on four versions of the runtime.

10 of 14 named signals had no effect or a marginal one when re-audited in November 2026. Only the four lit squares measurably steer the agent. Knowing which ones is the point of the project.

New environment with a strict wall between world and agent, plus textbook baselines (Q-learning, Dyna-Q, model-based planning). Two gates pass, one fails on calibration.

Limits and next steps

What this project is not, and where it goes next.

Not claimed

  • It is not a simulation of a real fly brain. The name is an inspiration. The graph is 20 hand-labelled concepts, not connectome data.
  • It is not a demonstrated cognitive architecture. The audit verdict still stands.
  • The results describe one small graph. They have not been tested on larger or partially hidden worlds.
  • No paper or outside reproduction exists yet.

Next

  • Fix the planner's calibration, the one failed check on the new testbed.
  • Put the original agent on the same test battery as Q-learning and Dyna-Q, with equal information.
  • Scale the testbed: bigger, noisy, partly hidden worlds.
  • Publish the raw data and a short write-up of the negative results.
