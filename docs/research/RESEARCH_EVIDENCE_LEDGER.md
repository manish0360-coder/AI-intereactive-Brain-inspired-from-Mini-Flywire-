**Verification pass 2 (2026-11-14, at HEAD `c43e167`):** the rows that the first pass had marked "Skimmed", "Not read" or
"not verified from primary evidence" were re-checked against their primary records. **54 of the 55 study directories now have a
primary record read**: 31 from a results file or results record (in full, or the summary keys of a large JSON), 21 that have no
result of their own from their README, script header or governing memo, and 2 (H1-R, COG-A / ACQ-1) from the governing ruling
only, because both are VOID. The first pass had 13. **Still not verified: `experiments/m7`** (the G15 values exist in no tracked

code: the Phase 1.0 gate counts, the registry "5,495 differential cases" figure, and the outcome of the `m38` gate.
Large JSON files were read by their top-level summary keys only; per-configuration arrays and raw data were not read.
It changes no study, ruling, label or result. Where this ledger and a study's own record differ, the study's record governs.

**Rules used.**
- Every number is copied from the file named in the "primary evidence" column. Nothing is recomputed. No gate, test or experiment was run for this audit.
- "Recorded verdict" is the label as written in the record. "Classification" is the auditor's, exactly one of:
  Confirmed finding / Failed hypothesis / Inconclusive / Void / Unrun / Exploratory / Engineering gate (pass/fail) / Descriptive.
- A row marked **not verified from primary evidence** means the auditor did not open that study's primary result file; its content comes from a secondary record that is named.
- ACQ-1 is VOID under D-035. Its numerical estimate is deliberately not reproduced anywhere in this ledger.

Companion files: [`NEGATIVE_FINDINGS.md`](NEGATIVE_FINDINGS.md), [`FILE_COVERAGE_MANIFEST.md`](FILE_COVERAGE_MANIFEST.md).

**Global caveat that applies to every MiniFlyWire-agent row.** All agent studies run on one graph
(`connections.json`: 20 nodes, 39 edges — `experiments/cf00_audit/README.md`), goals {8, 12, 16, 19} or a single goal.
"Worlds" are seed-generated hidden-reliability configurations and agent seeds on that one graph, not different graphs.
Nothing has been independently reproduced.
